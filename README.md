# Prime Download Manager 3.0.46 (Qt 6 C++ Edition)

High-performance, modern native download manager built with Qt 6 C++, featuring IDM-style browser integration, 32-thread multi-segmented downloading, and automatic lossless video stream capture.

## Build & Development

- **IDE:** Qt Creator / Visual Studio 2022
- **Framework:** Qt 6.8+ (Core, Gui, Widgets, Network, Concurrent)
- **Compiler:** MSVC 2022 (x64) / C++20
- **Build System:** CMake / qmake

### Quick Build
```cmd
cd src-qt
build.bat
```
Output binary generated in `src-qt/build/Release/PrimeDownloadManager.exe`.
